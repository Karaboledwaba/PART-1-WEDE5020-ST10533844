# FlowTech Plumbers - Web Development Project

## Project Overview
This repository contains Part 1 of the website design application deployment built specifically for FlowTech Plumbers.

## Objectives
- Launch an interactive mobile-responsive interface.
- Deploy an online inquiry capture framework module.

## Website Architecture Map
- `index.html` (Landing homepage showcase summary)
- `about.html` (Corporate identity history and credentials)
- `services.html` (Plumbing specializations matrix breakdown)
- `enquiry.html` (Dynamic intake appointment validation booking form)
- `contact.html` (Map directions, physical address grid details, and click-to-call triggers)
